# Component Inventory

Every distinct UI element on the 99Ravens site, how it's built, and what CSS classes drive it.

## 1. Notification Strip
**Location:** Fixed to top of viewport
**Classes:** `.notification-strip`, `.notification-content`, `.notification-label`, `.notification-link`, `.notification-close`
**Behavior:** Slides down on load (delayed 800ms). Dismissible via X button. Adds `body.has-notification` which pushes content down 70px. Uses `sessionStorage` (does not persist across sessions - shows every visit).
**Structure:**
```
.notification-strip
  .notification-content
    span.notification-label ("New")
    a.notification-link (text + optional arrow)
  button.notification-close (two rotated spans forming X)
```

## 2. Intro Video Overlay
**Location:** Fixed full-screen, z-index 9999
**Classes:** `.intro`, `.intro-video`, `.intro-skip`
**Behavior:** Plays video, auto-transitions to site on video end. Skip button fades in after 1.5s. Skipped entirely on mobile and for returning visitors (sessionStorage check). Fades out with opacity transition.
**Structure:**
```
.intro
  video.intro-video (autoplay muted playsinline)
  button.intro-skip ("Enter" + arrow span)
```

## 3. Header
**Location:** Top of site-wrapper, below notification
**Classes:** `.header`, `.logo-btn`, `.logo-img`, `.header-right`, `.menu-toggle`, `.menu-text`, `.menu-icon`
**Behavior:** Logo click returns home. Menu button toggles hamburger overlay. Two horizontal lines in menu icon animate on hover.
**Structure:**
```
header.header
  button.logo-btn > img.logo-img
  .header-right
    button.menu-toggle
      span.menu-text ("Menu")
      .menu-icon > span + span
```

## 4. Navigation Overlay (Hamburger Menu)
**Location:** Positioned absolute, top-right below header
**Classes:** `.nav-overlay`, `.overlay-menu`, `.overlay-link`, `.overlay-num`, `.overlay-divider`, `.overlay-link-secondary`
**Behavior:** Toggles via `.active` class. Slides down with fade. Links trigger section/detail opens or external navigation. Menu auto-closes on selection.
**Structure:**
```
.nav-overlay
  nav.overlay-menu
    button.overlay-link[data-section="experts"] > span.overlay-num + text
    button.overlay-link[data-section="brands"] > ...
    button.overlay-link[data-section="builders"] > ...
    .overlay-divider
    button.overlay-link.overlay-link-secondary[data-content="about"]
    a.overlay-link.overlay-link-secondary (Resources -> /resources/blogs/)
    button.overlay-link.overlay-link-secondary[data-content="contact"]
    a.overlay-link.overlay-link-secondary (Sign in -> external)
```

## 5. Home Page Layout Grid
**Classes:** `.main-content`, `.layout-grid`, `.cell-headline`, `.cell-nav`, `.cell-info`
**Structure:**
```
main.main-content
  .layout-grid (CSS Grid: 2 columns, 2 rows)
    .cell-headline (spans full width, row 1)
      h1.hero-message > .hero-line (x4, last one has .accent)
    .cell-nav (col 1, row 2)
      nav.primary-nav (display: contents, creates 3-col sub-grid)
        .nav-item[data-section] (x3)
          button.nav-link
            span.nav-prefix ("For")
            span.nav-title ("Experts" / "Brands" / "AI Builders")
    .cell-info (col 2, row 2)
      nav.secondary-nav
        a.secondary-link (About, Resources, Contact)
        .social-links > a.social-link (LinkedIn SVG, YouTube SVG)
```

## 6. Section Layer (Experts / Brands / Builders)
**Location:** Absolute positioned over main content, z-index 700
**Classes:** `.section-layer`, `.section-content`, `.section-main`, `.section-header`, `.section-number`, `.section-title`, `.section-statement`, `.section-subtitle`, `.section-footer`, `.section-desc`, `.section-cta`, `.section-index`, `.index-header`, `.index-list`, `.index-item`, `.index-num`, `.index-title`, `.index-desc`
**Behavior:** Slides up from bottom via `translateY(100%)` -> `translateY(0)` when `body.page-open` is set. Content is dynamically generated by `openSection()` in JS.
**Structure (generated by JS):**
```
.section-layer
  .section-content (CSS Grid: main area + 320px sidebar)
    .section-main
      .section-header
        span.section-number ("01")
        h2.section-title ("For Experts")
      .section-statement
        h1.section-subtitle ("The talent agency for...")
      .section-footer
        p.section-desc (long description)
        button.section-cta ("Apply for Representation")
    .section-index
      .index-header ("Services")
      .index-list
        .index-item[data-index] (first has .active)
          span.index-num ("01")
          .index-title ("We are your Platform.")
          .index-desc (description, hidden by default)
```

## 7. Section Navigation Arrows
**Location:** Fixed bottom-right, z-index 750
**Classes:** `.section-nav-arrows`, `.nav-arrow`, `.nav-arrow-prev`, `.nav-arrow-next`
**Behavior:** Only visible when section is open. Navigate between Experts <-> Brands <-> Builders. Disabled state at boundaries. Arrow keys also work.
**Structure:**
```
.section-nav-arrows
  button.nav-arrow.nav-arrow-prev ("←")
  button.nav-arrow.nav-arrow-next ("→")
```

## 8. Detail Panel (About / Contact)
**Location:** Fixed full-screen, z-index 1000
**Classes:** `.detail-panel`, `.panel-content`, `.panel-left`, `.panel-left-header`, `.panel-home-btn`, `.panel-logo`, `.panel-hero`, `.panel-left-footer`, `.panel-right`, `.panel-right-header`, `.panel-close`, `.panel-right-content`
**Behavior:** Fades in/out via `.active` class. Content generated by `openDetail()` in JS. Close button or Escape key dismisses. Logo clicks return home.
**Structure (generated by JS):**
```
.detail-panel
  .panel-content (flex row, 50/50)
    .panel-left
      button.panel-left-header.panel-home-btn > img.panel-logo
      .panel-hero > h2 (headline)
      .panel-left-footer > p (footer text)
    .panel-right
      .panel-right-header > button.panel-close (two rotated spans = X)
      .panel-right-content (scrollable)
        [About: .letter with paragraphs and .letter-signature]
        [Contact: .contact-emails, .office-locations, .constellation-map, .city-list]
```

## 9. Form Modal
**Location:** Fixed full-screen, z-index 2000
**Classes:** `.form-modal`, `.form-modal-backdrop`, `.form-modal-content`, `.form-modal-header`, `.form-modal-title`, `.form-modal-close`, `.form-modal-intro`, `.form-modal-body`
**Behavior:** Opens from CTA buttons in sections. Dark backdrop (85% opacity). HubSpot form rendered inside body div. Closes on backdrop click, X button, or Escape.
**Structure:**
```
.form-modal
  .form-modal-backdrop
  .form-modal-content
    .form-modal-header
      h3.form-modal-title
      button.form-modal-close (two rotated spans = X)
    p.form-modal-intro (hidden when empty)
    .form-modal-body (HubSpot form injected here)
```

## 10. Contact Constellation Map
**Location:** Inside Contact detail panel right content
**Classes:** `.constellation-map`, `.map-constellation`, `.constellation-line`, `.constellation-node`, `.node-pulse`, `.node-core`, `.node-label`, `.coord-text`, `.city-list`, `.city-item`, `.city-name`, `.city-detail`
**Behavior:** SVG with 4 city nodes connected by dashed lines. Nodes have pulsing orange circles (staggered animation). Below map is a text list of cities.
**Structure:**
```
.constellation-map
  svg.map-constellation (viewBox 300x200)
    line.constellation-line (x6 connections)
    g.constellation-node (x4: SF, TO, WL, LA)
      circle.node-pulse (animated expanding ring)
      circle.node-core (solid orange dot)
      text.node-label (city abbreviation)
    text.coord-text (latitude annotations)
.city-list
  .city-item (x4)
    span.city-name
    span.city-detail
```

## 11. About Page Letter
**Location:** Inside About detail panel right content
**Classes:** `.letter`, `.letter-signature`, `.signature-img`, `.signature-name`, `.signature-title`, `.founder-link`
**Behavior:** Scrollable letter with drop cap on first paragraph, signature image at bottom, founder name links to LinkedIn.
**Structure:**
```
.letter
  p (multiple paragraphs, first has CSS drop-cap)
  .letter-signature
    img.signature-img
    p.signature-name > a.founder-link
    p.signature-title
```
